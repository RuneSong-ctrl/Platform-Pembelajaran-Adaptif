# 📝 Learning Proposal: EduAdapt Project Context & UI Preferences

## 1. Summary of Identified Patterns & Rules
- **Design System Style**: Playful Duolingo-inspired design (chunky 3D push-down buttons `border-b-4`, stepping-stone winding learning path nodes, lively gamified feedback with streak 🔥, XP 💎, and health/energy ❤️ counters).
- **Core Architecture Metaphor**: 
  - **AI = Otak (Brain)**: Asesmen diagnostik gaya belajar, Dynamic Difficulty Adjustment (DDA), dan auto-generation materi/kuis/evaluasi/tugas yang ter-grounding 100% pada dokumen guru.
  - **Blockchain = Brankas Kredensial Aman (Secure Vault)**: Pencatatan tamper-proof capaian kompetensi dan ijazah mikro siswa.
- **Teacher Workflow**: Google Classroom-inspired class & rombel management (Class codes, student rosters, gradebook, and drag-and-drop document grounding).
- **Parent Workflow**: Simple multi-child account linking & Knowledge Map visualization.
- **Execution Target**: Implemented directly in Antigravity Web App (React + Tailwind CSS / modern CSS).
